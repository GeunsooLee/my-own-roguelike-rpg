# My Own Roguelike RPG

슬롯 로그라이크 게임 **My Own Roguelike RPG**의 이용약관·개인정보처리방침 페이지입니다. GitHub Pages로 공개됩니다.

- 언어 자동 선택: https://geunsoolee.github.io/my-own-roguelike-rpg/
- 한국어(원문): https://geunsoolee.github.io/my-own-roguelike-rpg/ko/
- English · 日本語 · 简体中文 · 繁體中文 · Deutsch · Français · Español · Português (Brasil) · Русский: `/<en|ja|zh_cn|zh_tw|de|fr|es|pt_br|ru>/`

페이지는 게임 저장소의 `tools/build_legal_pages.py`가 `docs/legal/src/`(한국어 원문 + 번역 JSON)로 생성합니다.
여기 HTML을 직접 고치지 말고 원문을 고친 뒤 다시 생성해 주세요. 번역본과 원문이 다르면 한국어 원문이 우선합니다.
